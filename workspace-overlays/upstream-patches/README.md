# 上游本地修改保留

`manifest.json` 记录 2026-10-14 的上游本地状态、基线提交及可导出补丁的 SHA256。五份补丁保存已有 AGENTS 修改；没有改写上游文件或提交，没有自动应用补丁。

四个嵌套部分克隆缺少基线对象，无法在离线检查中完整导出其已暂存删除。清单保留路径、状态与错误；这些 checkout 仍需核对。未跟踪数据只记录文件名，没有把数据集复制进 Git。此目录不构成这些机器数据的完整备份。

需要恢复某份补丁时，先核对目标仓库 HEAD 与记录 commit 一致，再在获得授权的开发 checkout 中执行 `git apply --check <patch>`，检查通过后决定是否应用。不要把改变运行规则的补丁当成依赖安装步骤。
